## 0.2.0

First public release. Faber was developed in a private repository before this
version, so this entry describes what the product does rather than listing that
history change by change. Later entries are generated by release-please.

### Features

**Resume builder**

- Resume catalog for creating, renaming, and deleting resumes, with configurable
  per-plan limits enforced by an authorization policy.
- Two-pane builder: an accordion section editor beside a live PDF preview with
  zoom and page navigation, plus a dedicated mobile layout.
- Sections for personal details, professional summary, experience, education,
  courses, skills, languages, links, and hobbies, with reorderable sections and
  entries.
- Shared rich text editor for the summary and hobbies, capped at 200 characters,
  whose formatting is preserved in the PDF.
- Resume titles are stored independently, so editing a person's name no longer
  renames the resume.
- Server-side PDF generation and download.

**Accounts**

- Sign-up with email verification, sign-in, sign-out, and forgot/reset password,
  backed by Keycloak.
- Account page for updating the user profile.
- Rate limiting on authentication, identity, user, and resume endpoints and on
  outbound email, with a shared `429` response contract.

**Interface**

- Angular standalone application with a shared `fb-` component library —
  buttons, inputs, select, date picker, accordion, rich text, and toasts.
- Light and dark themes, with colour tokens audited for WCAG AA contrast.
- Responsive navigation and a redesigned not-found page.

**Platform**

- Modular monolith on ASP.NET Core with FastEndpoints, EF Core on PostgreSQL,
  Redis, HashiCorp Vault, and OpenTelemetry, including structured logs.
- Local stack orchestrated by .NET Aspire; migration and bootstrap jobs bring a
  fresh clone to a working state without manual provisioning.
- Container images for the API, migrations, and web application, with the API
  image running on the ASP.NET runtime rather than the full SDK.

### Project

- Licensed under Apache-2.0, with a security policy, contribution guide, and
  code of conduct.
- Continuous integration builds and tests the backend, frontend, and all three
  container images, lints pull request titles, and scans for secrets with
  Gitleaks and TruffleHog.
- Workflow actions are pinned to commit SHAs with least-privilege permissions,
  and dependency updates are managed by Dependabot.
